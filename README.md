# Web Dev Project

## Структура

- **scss/** — исходники стилей (Sass)
- **css/** — скомпилированные стили (автоматически)
- **index.html** — главная страница

## Как запустить

1. Установи расширения в VS Code:
   - Live Sass Compiler (Glenn Marks)
   - Live Server (Ritwick Dey)
2. Открой `index.html`
3. Правой кнопкой → **«Open with Live Server»**
4. Редактируй `scss/main.scss` — CSS будет обновляться автоматически

## Технологии

- HTML5
- SCSS → CSS (через Live Sass Compiler)
- BEM-методология
- Emmet для быстрой вёрстки
